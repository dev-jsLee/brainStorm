# i18n — 언어 사전과 단어집

brainStorm 의 화면 · 서버 안내 · 에이전트 규약 문구는 모두 이 폴더의 사전에서 나온다(마스터 #821·#823).
**번역이 마음에 안 들면 고친다** — 사전 파일 한 줄을 고치면 된다. 사람이든 AI 든.

| 파일 | 무엇 |
|---|---|
| `ko.json` | **원본 사전.** 평평한 키 → 한국어 문자열. 새 문구는 여기에 먼저 넣는다 |
| `en.json` 등 `<언어>.json` | 같은 키 → 그 언어 문자열. 파일 이름이 언어 코드(`ja.json` · `zh-TW.json`) |
| `glossary.json` | **단어집.** 핵심 용어(스레드 · 전달 · 요청 · 보류 · 세대 …)를 언어마다 어떤 낱말로 옮기는지. 번역은 이 표를 따른다 |

## 문자열 규칙

- 자리표시는 `{이름}` — 번역에서도 **같은 이름을 그대로** 둔다(순서는 바꿔도 된다). 예: `"{n}개 남음"` → `"{n} left"`.
- `_meta.name`(언어 이름 · 언어 선택에 그대로 보인다) · `_meta.locale`(날짜·숫자 표기용 Intl 지역, 예 `en-US`).
- 키 앞머리는 쓰는 곳이다: `app.` `admin.` `runs.` `face.` `claims.` `html.`(화면) · `err.`(서버 오류 안내) · `srv.`(서버가 만드는 글) · `prompt.`(에이전트에게 싣는 안내) · `proto.`(끝줄 신호 낱말).
- 빠진 키는 `ko` 로 보이고, `ko` 에도 없으면 키가 그대로 보인다.

## 규약 낱말(`proto.*`)

에이전트가 답 끝줄에 적는 신호 낱말이다. 언어를 바꾸면 에이전트에게 싣는 규약(`prompt.*`)이 그 언어의 낱말을 쓴다.
서버는 **모든 언어의 낱말을 함께** 받는다 — 언어를 바꾼 직후 옛 낱말로 답해도 신호가 산다.

| 키 | ko | 쓰임 |
|---|---|---|
| `proto.request` | `요청` | 끝줄 `요청→ 이름` — 허용 짝에게 요청 |
| `proto.hold` | `보류` | 끝줄 `보류: 사유` — 받은 요청을 마스터에게 넘김 |
| `proto.question` | `질문` | 대면 모드 끝줄 `질문: …` |
| `proto.agreement` | `합의문` | 대면 모드 코드 블록 이름 ```` ```합의문 ```` |

`→ 이름`(전달) · `← 스레드제목`(끌어오기)은 화살표라 언어가 없다.
**`proto.*` 낱말은 언어끼리 겹치면 안 된다**(한 낱말이 두 신호로 읽힌다) — `npm run i18n:check` 가 본다.

## 새 언어 더하기 (AI 에게 시키는 순서)

1. `en.json` 을 `<코드>.json` 으로 복사한다(코드는 BCP 47 앞머리 — `ja` · `zh-TW` · `es`).
2. `glossary.json` 의 모든 항목에 `<코드>` 칸을 더한다 — 용어를 먼저 정한다.
3. `<코드>.json` 의 값을 모두 옮긴다. 원문 뜻은 `ko.json`, 용어는 단어집, 어조는 `en.json` 을 본다. `{자리표시}` 는 그대로.
4. `_meta.name`(그 언어로 쓴 언어 이름) · `_meta.locale` 을 채운다. `proto.*` 은 그 언어의 짧은 낱말 하나씩(다른 언어와 안 겹치게).
5. `npm run i18n:check` — 키 누락 · 남는 키 · 자리표시 어긋남 · 단어집 칸 · 규약 낱말 겹침을 본다. 통과해야 한다.
6. `npm run build` 뒤 서버를 다시 띄우면 언어 선택에 나타난다(코드 수정 없음).

## 새 문구 더하기 (개발할 때)

화면은 `t('키', {값})`, HTML 은 `data-i18n="키"`(글자) · `data-i18n-attr="title:키;placeholder:키"`(속성).
서버는 `t(lang, '키', {값})`(`src/i18n.ts`) — 언어는 `store.lang()`(에이전트·서버 글) 또는 요청 언어(오류 안내).
`ko.json` 과 **지금 있는 모든 언어**에 같은 키를 넣는다(못 옮기면 영어라도 넣는다 — check 가 빠진 키를 막는다).
